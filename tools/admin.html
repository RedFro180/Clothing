How this works

This page only edits a copy. Nothing on your live site changes until you replace site/config.js.

  1. Change what you want below. Press Check. Fix anything in red.
  2. Press Copy new config.js.
  3. On GitHub, open site/config.js → pencil (edit) → select all → paste → Commit changes.
  4. Your host redeploys in about a minute. If anything looks wrong, use the host's Rollback to the previous version.
